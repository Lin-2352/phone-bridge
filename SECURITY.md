# Security policy

Phone Bridge handles clipboard contents, files, input control and camera/mic streams, so security reports are taken seriously.

## Reporting a vulnerability
Please do not open a public issue. Use GitHub's private vulnerability reporting on this repository (Security tab, "Report a vulnerability"). Include affected version, steps to reproduce and impact.

## Scope
Pairing and authentication, transport encryption, relay behaviour, file/path handling, clipboard handling, input injection and the virtual camera/microphone components.

## Status
The project is in early development (Phase 0) and has had no external security audit.
