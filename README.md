# Phone Bridge

Open-source, privacy-first Android + Windows continuity: shared clipboard, AirDrop-style file transfer, Handoff, PC keyboard/mouse control of the phone, and the phone as a webcam. Works on the same LAN and across networks, with end-to-end encryption.

Status: Phase 0 (architecture and spikes). Nothing usable yet. See `docs/DECISIONS.md`.
