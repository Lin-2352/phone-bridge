**Goal:** an opt-in update check that can only ever point at a version the owner signed, a Windows installer with a scoped Private-network firewall rule and Public-network guidance, optional code signing that stays idle without secrets, an ARM64 build, SBOMs, third-party notices, and a least-privilege publish job.

**Tech Stack:** Rust 1.99.1, `ed25519-dalek`, `serde_json`, Inno Setup, `cargo-cyclonedx`, CycloneDX Gradle plugin, `cargo-about`, GitHub Actions (pinned by SHA).

## Review Focus
1. **Replay or frozen manifest:** an old signed manifest must not be accepted again. Tests: `stale_manifest_rejected`, `never_offers_installed_version`, `future_dated_manifest_rejected` (M10.1).
2. **Key rotation locks the owner out or lets an attacker rotate:** `rotation_requires_current_key_signature`, `rotation_chain_is_one_step_only`, `unknown_key_is_rejected` (M10.1).
3. **Hostile manifest bytes:** oversize, nested, duplicate keys, huge arrays never crash or allocate unbounded. Fuzz target + `oversize_manifest_rejected` (M10.1).
4. **Installer firewall rule too wide, or left behind:** program-scoped, UDP, Private only; removed on uninstall. Test: `scripts/check-installer.ps1` asserts the `.iss` text (M10.4).
5. **Secrets leak into logs or run for fork PRs:** signing step skipped when absent, never echoes a secret. Test: workflow lint in `scripts/check-workflows.sh` (M10.3, M10.9).

## Rulings already made
- Ruling (owner, 2026-11-08): the update flow is "verify, then open the release page". No PC self-swap, no in-app APK install, no `REQUEST_INSTALL_PACKAGES`.
- Ruling (owner): the real Ed25519 public key is generated by the owner offline. This milestone ships verifier, signing tool and a test key; embedding the real public key is a stop-and-ask step recorded in PROGRESS as "OWNER KEY".
- Ruling (owner): PBD1 stays through 0.3.0 (M11 records it).
- Ruling: manifest = `release-manifest.json` + detached `release-manifest.json.sig` (Ed25519 over the exact bytes). Fields: `version` (semver), `date` (UTC RFC 3339), `artifacts[] {name, url, sha256, size}`, optional `next_key` and `next_key_sig` (the current key signs `"relay-next-key:" + next_key`). Only `https://github.com/<owner>/<repo>/releases/` URLs are accepted as artifact links.
- Ruling: anti-rollback = never offer `version <= installed`; reject `date` older than the last accepted manifest date (stored locally) or more than 7 days ahead of the clock; the UI shows the manifest date so a frozen "latest" is visible.
- Ruling: checks run only on "Check now" and, if the person enabled it, once a day while the PC main window or the Android app is in the foreground.
- Ruling: Windows signing reads secrets `WIN_SIGN_CERT_PFX_BASE64`, `WIN_SIGN_CERT_PASSWORD` or a custom `WIN_SIGN_COMMAND`; absent -> step logs "signing skipped: no secrets" and the job stays green; never on `pull_request` from forks.
- Ruling: installer is per-user (`{userpf}`), no admin except the firewall rule which uses a one-time elevated `netsh` call with a UAC prompt, program-scoped, UDP, profile Private; uninstall removes it.
- Ruling: Public-network detection uses `INetworkListManager` (no admin), message text in `strings.rs`, shown in the installer finish page and on portable first run; README aligned.
- Ruling: ARM64 = cross-compile in CI (`aarch64-pc-windows-msvc`), no tests, camera DLL "untested on ARM64" in README; `deny.toml` targets gain it.
- Ruling: SBOM via `cargo-cyclonedx` (Rust) and CycloneDX Gradle plugin (Android), uploaded as release artifacts; NOTICE via `cargo-about` + a Gradle license report, committed, regenerated by `scripts/gen-notices.sh`.
- Ruling: publish job split: `contents: read` default, `packages: write` only on the push job, `id-token` none, tokens not shared between steps.

## Shared interfaces (defined in M10.1)
```rust
// crates/pb-update/src/lib.rs
pub struct Manifest { pub version: Version, pub date: OffsetDateTime, pub artifacts: Vec<Artifact>, pub next_key: Option<[u8; 32]> }
pub struct Artifact { pub name: String, pub url: String, pub sha256: [u8; 32], pub size: u64 }
pub struct TrustState { pub keys: Vec<[u8; 32]>, pub last_date: Option<OffsetDateTime> }   // persisted by the app
pub enum Verdict { UpToDate, Available(Manifest), Rejected(Reject) }
pub enum Reject { TooBig, BadJson, BadSignature, UnknownKey, Rollback, Stale, FromTheFuture, BadUrl }
pub fn verify(bytes: &[u8], sig: &[u8; 64], trust: &TrustState, installed: &Version, now: OffsetDateTime) -> (Verdict, TrustState);
```
